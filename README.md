# Sherard Daniel Vyse CV Website

This is a static CV website built for GitHub Pages.

## Files

- `index.html` - Main webpage
- `styles.css` - Website styling
- `assets/Sherard_Daniel_Vyse_CV.pdf` - Downloadable PDF CV
- `assets/Sherard_Daniel_Vyse_CV.docx` - Downloadable DOCX CV
- `LICENSE` - All rights reserved copyright notice
- `.nojekyll` - Ensures GitHub Pages serves the site as plain static files

## Upload to GitHub Pages

1. Create a GitHub repository, for example `cv` or `portfolio`.
2. Upload all files in this folder to the root of the repository.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Save. GitHub Pages will publish the site after the deployment finishes.
